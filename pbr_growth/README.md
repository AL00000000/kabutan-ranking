# PBR要請とグロース株の検証

「2023年3月のPBR是正要請でプライム/スタンダードの還元が厚くなり、個人の資金が
グロースに入らなくなった。結果グロースは決算のたびに振れるだけで、間の期間に
上昇しなくなった」という仮説の検証。

## 結論（Phase 0 時点）

1. **結果は劇的に確認された。** 3年で株価2倍の達成率が逆転している。
   グロース 22.9%(2017-19) → 8.1%(2023H2-26)、プライム 7.4% → 20.9%。
2. **資金の流れの仮説は否定された。** 個人はグロースを買い越し続けており
   (2019年 +451億円 → 2025年 +4,871億円)、プライムは大幅に売り越している
   (2025年 -37,461億円)。プライムを買ったのは外国人(2025年 +57,739億円)。
3. **値動きの質の変化はグロース側にはない。** グロースの勝者は昔から上昇が
   7〜8日に集中していた(2017-19が8日、2023H2-26が7日)。変わったのはプライムで、
   勝者が121社→351社に増え、上昇の仕方が11日→13日とより分散した。

体感された「イベント以外で上がらない」はグロースで起きた変化ではなく、
グロースとプライムの差が開いたことの反映と解釈できる。

## 重要な方法論上の注意

**集中度(conc5)とリターン内訳(ret_ev/ret_nonev)は日次リターンの順序を
入れ替えても値が変わらない。** 「絶対値上位N日」は集合演算なので当然で、
これらは分布の裾の形を要約しているだけであり、イベントのタイミングの情報を
まったく持たない。実際にシャッフルして確認済み(conc5=0.0831が完全に不変)。

順序に依存する = タイミングを測れるのは **分散比(vratio)と連騰日数(runs)だけ**。

したがって「決算にリターンが集中するようになったか」は統計的ジャンプでは
原理的に測れない。決算発表日データが要る(Phase 1・未着手)。

その他:
- 分散比はビッド・アスク・バウンスで1日分散が膨らむため、流動性の低い銘柄ほど
  低く出る。**市場間の水準比較は無効**で、同一グループ内の時系列変化だけが使える。
- 2024H2〜2025H1の集中度スパイクは3市場同時。2024年8月5日の暴落等の
  市場全体のイベントを拾っている。銘柄固有のイベントを見るには残差リターンが要る。

## 母集団の作り方（ここが肝）

JPXの上場銘柄一覧は現時点のスナップショットしか配っていない。そのまま使うと
**グロース→プライムに市場変更した銘柄が母集団から抜け**、「グロースは上がらなく
なった」が同語反復になる。2023-01のグロース513銘柄のうち18.9%が該当する。

Wayback から過去のマスタを復元して所属履歴を作り(`build_universe.py`)、
**各期間の期首時点の市場区分でコホートを固定**する。市場変更後も追跡を続ける。

消滅した43銘柄(2023-01コホートの8.4%)はYahooが上場廃止銘柄を404で返すため
価格データが取れない。TOBによる高値退出と経営難の廃止が混在しており、
除外がリターン分布をどちらに歪めるかは事前には言えない。

## スクリプト

| | |
|---|---|
| `fetch_10y.py` | 日足10年を `../cache_bars_10y/` へ。Yahooは `range=10y` なら10年返す(`max`は月足に落ちる) |
| `build_universe.py` | Waybackの過去マスタから所属履歴を復元 → `market_hist.json` / `universe.json` |
| `fetch_itype.py` | 投資部門別売買状況(週次)をWaybackから589ファイル。JPX本家は直近5週しか置いていない |
| `parse_itype.py` | 上記を解析 → `itype.json`。**差引きは売り側と買い側のどちらか大きいほうの行に書かれる**ので、行決め打ちだと売り越しの週を落とす。買い-売りで計算すること |
| `aggregate.py` | 銘柄×半期の指標 → `panel.json` |
| `report.py` | リターン内訳と「3年で2倍」の頭数 |
| `report_itype.py` | 市場別の個人・海外の売買 |
| `winners.py` | Q2。各期間の勝者だけを取り出して上昇の集中度を見る |

再取得は `py fetch_10y.py`(約35分) と `py fetch_itype.py`(約45分)。どちらもレジューム可。
