ネットの定義 … 現物ネット = 現物買 − 現物売 / 買い残ネット = 新規買 − 返済売 / 売り残ネット = 空売り + 新規売 − 返済買。日々の「買い合計 = 売り合計 = 出来高」および累計の「現物ネット + 買残ネット − 売残ネット = 0」を全20銘柄 × 44営業日で検算済みです。
指標の見方 … ②新規買÷発行済はその月にどれだけ信用買いが回転したかの熱量。③現物ネット÷発行済は現物の実需買い越しの厚み。④買残ネット÷発行済がプラスに大きいほど信用買い残が滞留していて上値のシコリになります。ほぼ全銘柄で④はゼロ近傍＝現物の買い越しを受けているのは信用買いではなく売り建て側、という構図です。①現物ネット÷買残ネットは④がゼロ近傍だと分母割れで発散するため、|④| < 0.05% の銘柄には * を付けて参考値としています。
注意 … 「空売り」列は当日中に買い戻される高頻度売買を多く含むため、⑤売り残ネットをそのまま信用売り残高の増加として読むことはできません。実残高は週次公表の信用残で別途確認してください。またこのデータは松井証券内の約定ではなく、市場全体の出来高を按分した当日推計値です。

出来高が52週間(365日)の最低を更新した銘柄です。出来高の枯れは相場の転換点のサインとして見るためのタブで、新高値タブとは逆に「動かなくなった銘柄」を拾います。
母集団は売買代金10億円以上の東証銘柄(東P/東S/東G)に監視銘柄リストの全銘柄を足したもの。出来高が枯れた銘柄は売買代金も落ちてランキングから消えてしまうため、監視銘柄はランキング圏外でも必ず判定します。
判定は2種類。単日 = 当日の出来高が、当日を含まない直近52週のどの日よりも少ない。5日平均 = 5日移動平均が、同じく直近52週のどの5日平均よりも少ない。単日は1日だけの偶然で反応しやすいので、枯れの判断には5日平均のほうが向きます。
ストップ高・安の気配日は除外しています。買い気配のストップ高は誰も買えないので出来高が極端に小さくなりますが、これは閑散ではなく過熱で、意味が逆になるためです(高値と安値が同値の日を気配とみなします)。過去の気配日も比較の窓から除いています。除かないと異常に低い出来高が52週最小として居座り、本物の閑散日が最低を更新できなくなるためです。
「52週平均比」= 当日出来高が52週平均の何%か。低いほど枯れています。「前回」= 直近1年で前に最低を更新した日と、そこからの営業日数。1年未満は上場から1年経っておらず比較期間が足りない銘柄です。列見出しクリックで並び替えできます。

売買代金ランキング(上位500位)に一度でも登場した銘柄を母集団に、開始日の終値を100として終了日の終値までの騰落率を並べたものです。株価はYahoo Financeの調整済み終値なので、期間中に株式分割・併合があっても騰落率は壊れません(配当・分配金も再投資したものとして調整された値です。指数の代理ETFも同じ調整値なので、「対TOPIX」は同じ土俵での比較になります)。
「対TOPIX」= 同じ期間のTOPIX(1306)の騰落率を引いた超過リターン。地合いぶんを除いてどれだけ強かったかを見るための列です。「期間高値」は開始日〜終了日の終値ベースの最高値、「高値比」は終値がそこからどれだけ下がったか(0%なら期間の最高値で引けている)、「最大上昇率」は開始日から期間高値までの上昇率です。高値比が大きくマイナスの銘柄は、期間中に急騰したあと大きく戻していることを意味します。
「平均売買代金」は直近20営業日の平均(終値×出来高)。小型株のノイズを外したいときは下限を入れて絞り込めます。「代金順位」は最新営業日の売買代金ランキング順位で、空欄は現在500位圏外の銘柄です。
開始日より前に上場していない銘柄・その日の株価が取れない銘柄は除外されます。列見出しクリックで並び替えできます(既定は騰落率の降順)。

数値はJPXが引け後に公表する確定値(立会内)です。ToSTNeT(立会外)・ETF・REITは含みません。「1位」「2位」はその日に最も売買代金の大きかった銘柄で、3市場を通した順位です。
JPXは市況を5営業日ぶん、売買代金ランキングを1営業日ぶんしか公開していません。過去に遡って取り直せないため、毎営業日18:30に取得してこのサイトに積み上げています。そのため集計開始は2026年8月19日で、それ以前のデータはありません。銘柄の1位2位も、記録を始めた日より前の分は空欄になります。
「値上がり」「値下がり」は3市場合計の銘柄数です(セルにカーソルを乗せると市場別の内訳が出ます)。売買代金が膨らんでいても値下がり銘柄のほうが多ければ、一部の主力株に売買が集中しているだけで物色の広がりは無いと読めます。
「最高比」は1日の売買代金・売買高それぞれの過去最高に対して、その日が何%かです。売買高(株数)のほうが素直な活況度の指標です。売買代金は株価水準が上がるだけで膨らむので、株価が5倍になれば同じ株数でも代金は5倍になります。Discord通知には売買高ベースの最高比だけを載せています。
