# 高配当上位50の25年 — 仮説検証レポートのソース

`docs/kensho.html`（サイトの「仮説検証」タブ）を作った素材一式。
GitHub Pages は `docs/` 以下のみ公開するため、このフォルダは公開されない。

## 検証内容
「東証の配当利回り上位50銘柄を均等に買い、入れ替わったら入れ替える」戦略と、
それに「時価総額1000億以上」を加えた戦略の、2001/12〜2026/08（24.7年）の成績。

自作バックテストは**していない**。現在上場中の銘柄しか手元になく、高配当スクリーンが
拾って消えた銘柄（そごう・マイカル等）が欠落して生存者バイアスが出るため。
代わりに条件が一致する実在の公表インデックスを使った。

### Yahoo の日経平均を使うときの注意（ハマりどころ）
`timestamp` は**JST基準の月初**。`utcfromtimestamp()` でそのまま月ラベルを作ると
1か月ズレて、日経公式値と最大5,700円ずれる。`+9*3600` してから月に落とすこと。
補正後は公式日次CSVと重なる45か月で**誤差0.00円**で一致する。

## 実行
```
python analyze.py     # 指数の読み込みと基本集計（analyze2.py がこれを exec する）
python analyze2.py    # 日経平均を足した集計 + chartdata2.json 出力
python build_site_page.py   # highdiv.html -> docs/kensho.html（サイト用ダーク固定）
```
`build_site_page.py` は Artifact 用の `highdiv.html`（head/body1-3/tail を結合したもの）を
入力にする。結合は analyze2.py の後に手で行った。
